# Plantão Calc

Calculadoras clínicas para beira-leito: cardiologia, respiratório, renal, nutrição, fármacos, eletrólitos, ácido-base, insulinoterapia, conversores e escalas de UTI, neurológicas e funcionais.

App web estático, responsivo e instalável no celular. Publicado via GitHub Pages.

Ferramenta de apoio: os resultados não substituem o julgamento clínico.
